Claim boundaryThis is a toy inspired by Collatz-style branching. No physical relation to early dark energy or derived Poincaré return map is established. Staying within the sampled range is not a proof of boundedness.

Rules, limits & source notes

Let b = ⌊λx / Vth⌋. F(x) = λx/2 when b is even; F(x) = 3λx + Vshift when b is odd.

  • The branch map and cobweb use a fixed x/y viewing window from 0 to 20. The orbit chart rescales to the observed values. Sampling a discontinuous branch map does not resolve every threshold visually.
  • The recurrence uses its raw next value. The finite run stops after recording the first value above 100, or after the chosen iteration count. The original value cap was removed because feeding min(F(x),100) back into the recurrence changed the system.
  • For example, λ = 1, Vth = 2, Vshift = 1 and x₀ = 2 produce 2, 7, 22, 67, 202 before this exhibit stops. “Left x ≤ 100” describes that finite observation.
