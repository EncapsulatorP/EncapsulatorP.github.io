Exact rule, hole mapping & source fidelity

a₀ = 0. Try aₙ₋₁ − n; use it if positive and new. Otherwise use aₙ₋₁ + n.

Finite horizon. N counts terms, including a₀, so there are N − 1 transitions. A hole is an integer h with 1 ≤ h < max(a) that is absent from these N terms. Addition may revisit values. The counts use every generated term; they do not estimate an infinite horizon.

Delay cloud. With M = max(a), the trajectory point at i is 2.2(aᵢ/M − ½, aᵢ₊₁/M − ½, aᵢ₊₂/M − ½), for 0 ≤ i < N − 2. A red hole h uses p = 2.2(h/M − ½), j = 0.025((h mod 6) − 2.5), and position (p + j, p − j, p). This preserves the supplied red diagonal and its six offsets.

Twisted Möbius view. Trajectories use u = 2πi/N, v = 0.9((aᵢ mod 6)/5 − ½), r = 1.1 + 0.6aᵢ/M and dᵢ ∈ {−1, 0, +1}, the direction into aᵢ. The position is ((r + v cos(u/2)) cos u, (r + v cos(u/2)) sin u, v sin(u/2) + 0.12dᵢ). A red hole uses u = 2πh/M, v = 0.9((h mod 6)/5 − ½), r = 1.1 + 0.6h/M, and no direction offset. In particular, the two angular coordinates use different inputs: index for the trajectory, value for the holes. This is the original illustrative mapping, not a derived manifold.

What is retained. Both source mappings, the 200–8,000 range, default 2,500 terms, camera position (2.4, 2.0, 2.8), 48° field of view, blue/green trajectories, red holes, axes, orbiting, zooming, theme switch and Gemini signature. The source colors a₀ green; it has direction 0 and contributes no transition. Both modes retain the source’s N − 2 trajectory points.

What is corrected or added. “Steps” is labeled terms, and the backward ratio uses N − 1. Source hole sampling is retained: every max(1, floor(H/4,000))-th hole is drawn, starting at the smallest; the displayed total H is unsampled. A local renderer, keyboard controls, explicit pause, reduced-motion support, hidden-view suspension and a Canvas projection fallback make the same scene usable on more devices. The surrounding paper palette follows the Atlas; midnight is the initial scene theme.
