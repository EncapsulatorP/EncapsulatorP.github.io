Rules, limits & source notes

a₀ = 0. Try aₙ₋₁ − n; use it if positive and not yet visited. Otherwise set aₙ = aₙ₋₁ + n.

  • The sequence is named for Bernardo Recamán Santos. Gemini’s contribution here is the interactive coordinate visualization. An N-step sample contains N + 1 terms, a₀ through a_N.
  • Delay coordinates: (aₙ, aₙ₋₁, aₙ₋₂). Time/value coordinates: (n, aₙ, aₙ₋₁). Each display is scaled from the selected finite sample.
  • Normalized delay uses (aₙ/n, aₙ₋₁/(n−1), aₙ₋₂/(n−2)) starting at n = 3. This avoids the original undefined a₀/0 coordinate. Its scale is computed from observed ratios, without assuming aₙ grows like 2n.
  • Addition and subtraction keep separate colors. Instanced points preserve the original 3D scene while reducing the number of draw calls. Drag to orbit, scroll to zoom; focus the view for arrow-key orbiting, +/− zoom and R to reset the camera.
