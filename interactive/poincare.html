Claim boundaryThis is Gemini’s named Poincaré exhibit, presented as a defined threshold-map toy. No return map derived from a continuous physical system, cosmological claim or general stability theorem is established.

Map, cobweb & source notes

b(x) = ⌊λx / Vth⌋.
F(x) = λx/2 when b(x) is even;
F(x) = 3λx + Vshift when b(x) is odd.
xn+1 = F(xn).

The cobweb starts at (x₀, 0). Each iteration first moves vertically to (xn, xn+1), then horizontally to (xn+1, xn+1) on y = x. “Next leg” reveals one of those two moves. The bright gold segment is the latest move; the coral trail is the revealed history. A faint full trace and the complete finite orbit remain available as context.

  • The original defaults and ranges are retained: λ = 0.85 (0.1–1.5), Vth = 2 (0.5–5), shift = 1 (0–5), x₀ = 1.5 (0.1–10), and N = 50 (10–200).
  • Raw recurrence records the first value above 100 and then stops, or completes the chosen N steps. This is a display cutoff, not a proof that the orbit diverges. A finite run below 100 does not establish boundedness.
  • Original capped replay deliberately reproduces the supplied script’s feedback xn+1 = min(F(xn), 100). That is a different recurrence. Its original “stop above 100” condition could never trigger after capping. This comparison is labeled wherever it is selected.
  • The “Jump example” loads λ = 1, Vth = 2, shift = 1, x₀ = 2. Raw mode gives 2 → 7 → 22 → 67 → 202; capped replay instead feeds 100 back after 67. A dashed cap line and an orange correction segment show where replay changes the map.
  • “Orbit focus” fits the finite run so the cobweb remains legible. “Original 0–20” preserves the source’s return-map window and may clip the trace. Threshold bands are drawn separately, with filled left and open right endpoints, so the plot does not join across a jump.
  • Play pauses when this exhibit is hidden. Reset returns to (x₀, 0); Play at the end replays from the start. Animation is off initially.
