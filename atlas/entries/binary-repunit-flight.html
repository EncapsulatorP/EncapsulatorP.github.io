A binary repunit hands its first flight to a power of three

The shortcut Collatz map has a closed form for the first k updates from 2^k−1.

Recovered Collatz / repunit story

S(n)=n/2 if even; S(n)=(3n+1)/2 if odd
S^j(2^k−1)=3^j 2^(k−j)−1,  0≤j≤k, k≥1

Why follow it

It identifies an exact initial flight inside a trajectory whose later behavior can remain difficult.

For j<k, the displayed value is odd. Applying the shortcut odd branch gives 3^(j+1)2^(k−j−1)−1, which proves the formula by induction.

At k=5 the values are 31,47,71,107,161,242. At the end of the k-step flight the orbit reaches 3^k−1.

These counts use the shortcut map, unlike the standard-map 111-update count for seed 27 elsewhere in the atlas. The formula says nothing by itself about the subsequent stopping time.

Next experiment or question

Formalize the finite-flight induction and compare the next valuation v₂(3^k−1) across k.
