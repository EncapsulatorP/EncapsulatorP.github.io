The explicit map combines a Collatz integer extension with exponential iteration and controlled phase terms.

Why follow it

The landscape can be explored as a mathematical dynamical system, with survival time and phase response tied to a reproducible map.

The model file defines the effective base and its tanh phase and paired terms. The logarithm branch, reset rule, escape threshold and iteration count are part of an experiment’s definition.

A point that survives N steps supplies finite-time evidence. It does not establish an infinitely bounded orbit. Escape sectors and phase fringes are useful numerical observables when settings remain attached.

The exact integer spine and the conjugate-pair cancellation provide two independent controls for interpreting changes in the image.
