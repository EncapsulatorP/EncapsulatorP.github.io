An exponential map leaves one value out

The generic closure F = exp(H) − 1 has an exact omitted value and an exact description of its zeros.

Spectral Collatz-lift research · recovered source

F(z) = exp(H(z)) − 1
F(z) ≠ −1 whenever H(z) is finite
F(z) = 0 ⇔ H(z) ∈ 2πi ℤ

Why follow it

It gives root searches a simple mathematical check that remains valid independently of a particular lift model.

The complex exponential never vanishes. Its value equals one exactly at integer multiples of 2πi, proving both statements.

Numerical underflow can make a computed exponential look like zero, while clipping can change the equation being solved. Candidate roots should be checked in the original unclipped model.

The current source and older README use different lift definitions. This entry preserves the generic exact closure identity; their reported root counts are not combined into one verified result.
