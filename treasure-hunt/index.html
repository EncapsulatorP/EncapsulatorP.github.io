B05Two constructions of sixExact statement

Tadd(y) = frac(2·3ʸ), Tmul(y) = frac(6ʸ), y ∈ [0,1), N ≥ 1; orbit segments with the stated branch derivatives.

Each finite-time average uses exactly N terms, indexed 0 through N−1. The branch log derivatives are affine functions of y, so their averages and difference are exact functions of the respective orbit means.

B11Ordinary palindrome countExact statement

Independent uniform symbols; alphabet size integer q ≥ 2; string length integer n ≥ 1.

There are q^ceil(n/2) palindromes among qⁿ strings, so the probability is q^(−floor(n/2)). The q = 4, n = 40 example is exactly 2^(−40).

P = q−⌊n/2⌋   ·   q = 4, n = 40 ⇒ P = 2−40
Argument and qualification

The formula includes odd lengths. For reverse complementation with a fixed-point-free complement pairing, odd lengths are impossible and even lengths have probability q^(−n/2).

B12Global convergence of the alternating towersExact statement

Real c > 1, L = log c; v₀ ≥ 1; u = c^(−v), v = cᵘ.

F_L(v) = exp(L exp(−Lv)) maps [1,∞) into I = [1, exp(1/e)] and is a contraction there with uniform bound q = 4 exp(1/e − 2) < 1. The solution is unique and every stated initial value converges.

|F′L(v)| ≤ q = 4e1/e−2 < 1
Argument and qualification

Banach’s theorem proves convergence and uniqueness for this explicitly defined alternating-sign system. The residual estimate is an exact-arithmetic statement.

B13Sharp height and number of basesExact statement

The preceding alternating system, c > 1.

Read the later cubic argument

Set r* = 1 + √6 and F = f². Around either cycle point p = x±, write F(p + h) − p = −h + a±h² + b±h³ − r*³h⁴. Direct composition cancels the quadratic term and gives

The coefficient is negative at both cycle points. For sufficiently small nonzero h, the four-step return moves toward the cycle point without crossing it. This local conclusion uses the surviving cubic; a zero Lyapunov exponent alone would not establish it.
