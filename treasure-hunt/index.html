02 / Move the mathematics

Two places to land.
Four ways to point.

At one exact setting, the logistic map swaps two numbers. Its paired derivative has a different story: after a change of coordinates, an arrow makes a quarter-turn at each step.

Exact local resultf(x) = rx(1 − x)r = 1 + √6Open the proof · PDF →

Step 0 · start at the lower cycle point.

Why the arrow comes back

At the cycle points, the two derivatives multiply to −1. Put them in the paired matrix C. Then C² = −I and C⁴ = I. With a = √2 − 1 and S = diag(√a, 1/√a), the matrix S⁻¹CS is J = [[0, 1], [−1, 0]]. This is the clockwise arrow shown here.

The nonlinear fourth iterate still has degree 16. Its derivative is 1 at the cycle points; the function is not the identity.

The cubic that survives — read the new lemma

Set r* = 1 + √6 and F = f². Around either cycle point p = x±, write F(p + h) − p = −h + a±h² + b±h³ − r*³h⁴. Direct composition cancels the quadratic term and gives

f⁴(x± + h) − (x± + h) = −20r*²(2 ± √2)h³ + O(h⁴).

The coefficient is negative at both cycle points. For sufficiently small nonzero h, the four-step return moves toward the cycle point without crossing it. This local conclusion uses the surviving cubic; a zero Lyapunov exponent alone would not establish it.

This derivation is new to this edition. Its literature novelty has not been established.
